它替你演什么

不用切回终端，看一眼角落就知道

六种状态对应 Claude Code 的六种处境。气泡带点性格，不是仪表盘式播报。

在干活BUSY

它读文件、跑命令、写代码的时候，猫趴着敲小键盘。

等你决策WAITING

停在权限确认上就招手叫你，气泡标明是哪个项目、哪个工具。一声轻提示音，可关。

跑完了CELEBRATING

任务收工，庆祝几秒钟，然后回去待机。

出状况ALERT

报错了会炸毛，气泡常驻到你处理为止。这一处不出声。

你走开了SLEEP

键鼠几分钟没动它就打盹；你一回来，伸个懒腰醒过来。

摸一下PET

点它一下会有反应。没有养成、没有数值，纯陪着。

这只猫哪来的

它来自一张图

市面上的桌宠，每加一个形象都是美术几天的手工活。DeskCat 的形象是喂一张参考图， 让 AI 把九个状态全生成出来——所以它能有很多只，而不是就那么几只。

它有多安静

你不该在活动监视器里注意到它

桌宠是要挂一整天的东西。下面的数字是 release 版实测，不是估算。

0.0%空闲 CPU6 分钟 12 次采样，恒为零
71.7 MB常驻内存运行中进入平台期，不再增长
7.1 MB安装包原生 Apple Silicon / Intel
0对外网络连接只有一个本地回环监听

感知键鼠时只读系统的「距上次输入过了几秒」这一个数字，物理上拿不到你敲了什么。 全程不需要辅助功能授权。你的代码、对话、按键，一个字都不会离开这台电脑。
