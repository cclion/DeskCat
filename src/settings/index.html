形象

这只猫来自一张图 —— 以后你也可以用自己的图生成一只
大小拖动时桌面上的它即时缩放

通用设置

它怎么陪着你,由你说了算
开机自启开机时自动把它请出来
全屏时隐藏演示、看视频时它自动回避
等你批权限时轻提示音只有这一处会出声,响一下就停
日常气泡也显示来源等你决策和出错时一定会标明项目;这里管的是干活等日常状态

陪伴感知

你在敲键盘它就陪你忙活,你走开它就打个盹
键鼠活动感知只取"在不在动"这一个信号,不记录任何按键内容
判定离开键鼠这么久没动就去打盹
−3 分钟＋

Claude Code

它跑任务的时候,猫替你盯着
未连接写入 hooks 后才能感知
判定闲置超过这个时间没有新事件,视为任务结束
−10 分钟＋
